# specs — @devdigest/e2e

Feature specs written before implementation: `NN-feature-name.md`. A spec states
*what* to build and its acceptance criteria — not *how*.

Not to be confused with the existing `*.flow.json` files in this directory —
those are declarative browser-test flows for the agent-browser runner
(see [../README.md](../README.md)), a separate thing from feature specs.
